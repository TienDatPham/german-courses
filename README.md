# german-courses

Dan's German C1 practice material: exercise sheets and flashcards as self-contained HTML pages (no network, no build step). Open `index.html` for the list of all pages.

## Contents
| Folder | What it holds |
| --- | --- |
| `grammatik-ubung-c1/` | Exercise sheets for *Grammatikübungen C1* (Hans Witzlinger, Deutsch – ABER HALLO!): one page per chapter (7 chapters) plus an overview and a single-page answer sheet |
| `ubungsgrammatik-fur-die-mittelstufe-c1/` | Answer sheets for *Übungsgrammatik für die Mittelstufe C1* (chapter 1 so far) |
| `new-words/` | Vocabulary tables (`*.md`, columns Worter, Definition, Beispiel, Note) and the flashcard pages made from them (`*-flashcards.html`) |
| `index.html` | Start page linking every page |

## How the pages work
- Answers, check results and flashcard marks are stored in the browser (localStorage), per page address. They are not synced between devices.
- Dark mode follows the system setting. The pages fit a phone screen.
- The HTML pages are generated files. Change the source (the Markdown table, or the skill that builds the sheets) and regenerate; do not hand-edit them.

## Generated by (skills in the parent `second-brain` repo, `.claude/skills/`)
- `/flashcard <table.md>`: flashcards from a Markdown table; `/flashcard --random X` makes `random-flashcards.html` from X random words of all tables in `new-words/`.
- `/neue-worter [-f] <word list>`: turns a word list from `raw/german/` into table rows in `new-words/`; `-f` also builds the flashcards.
- `/ubung-erstellen --exercise <pdf> [--answer <pdf>]`: exercise pages with answer fields and a Check button for a book in `raw/german/`.

## Viewing online
GitHub Pages serves the folder when enabled (Settings → Pages → Deploy from branch → `main`, `/ (root)`). On a free account this needs a public repo. The address is `https://tiendatpham.github.io/german-courses/`.

## Source books and privacy
The books (PDFs) are not in this repo; they stay in `raw/german/` of the private `second-brain` repo. This repo holds only Dan's own pages, vocabulary and exercise texts typed from the books for personal study.
